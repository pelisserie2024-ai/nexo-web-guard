Seguridad web defensiva

Conoce la exposición de tu sitio web sin ponerlo en riesgo

NEXO WEB GUARD realiza comprobaciones pasivas y de bajo impacto: cabeceras de seguridad, HTTPS y certificado, tecnologías detectadas, estado de PHP y vulnerabilidades conocidas (NVD/CVE) para las versiones que puedan verificarse. Todo con evidencia, grado de certeza y un informe PDF descargable.

Analizar un sitio web

Solo se realizan unas pocas solicitudes HTTP/HTTPS de lectura (robots.txt, página principal y una comprobación de redirección). Máximo 6 análisis cada 10 minutos por conexión.

Estado del análisis

    Funcionalidades

    Cabeceras de seguridad

    CSP, HSTS, X-Content-Type-Options, Referrer-Policy, Permissions-Policy y X-Frame-Options evaluadas según el contexto, sin marcar como vulnerable cualquier ausencia.

    HTTPS y certificado

    Disponibilidad de HTTPS, validez y caducidad del certificado, redirección de HTTP a HTTPS y contenido mixto.

    Detección de tecnologías

    PHP, WordPress, Joomla, Drupal, servidor, frontend y CDN, siempre con estado (Confirmado, Probable, No detectado, Desconocido), confianza y evidencia.

    PHP Security Analyzer

    Versión solo si hay evidencia verificable, comparación con el ciclo de soporte y consulta de CVE. Sin inferir versiones a partir del CMS.

    Vulnerabilidades CVE (NVD)

    Consulta a la API oficial de NVD con clasificación A, B o C según la certeza de la detección. Nunca se inventan resultados.

    Informe PDF y JSON

    Informe profesional generado en tu dispositivo con hallazgos, evidencias, recomendaciones, limitaciones y fuentes. Exportación JSON incluida.

    Límites del análisis

    • El análisis es externo y pasivo: solo ve lo que el sitio publica. No accede a cuentas, paneles ni archivos privados.
    • Las versiones obtenidas de cabeceras o del HTML son declaraciones del sitio, no verificaciones en el servidor.
    • La ausencia de una señal no demuestra que una tecnología no esté presente. Un resultado «No detectado» no es un resultado negativo seguro.
    • Lo que no puede comprobarse se muestra como «No verificable con las comprobaciones disponibles».
    • No se hacen pruebas de explotación, fuerza bruta, escaneo de puertos ni enumeración de directorios o plugins.
    • Un análisis externo no garantiza la ausencia de vulnerabilidades.

    Aviso de uso autorizado

    Utiliza esta herramienta únicamente con sitios de tu propiedad o con autorización expresa de su titular. La casilla de confirmación no sustituye a los controles técnicos del servidor, que bloquean direcciones internas, limitan la frecuencia de uso y respetan el archivo robots.txt del sitio analizado.

    Privacidad

    • No hay cuentas, inicio de sesión ni base de datos. Los resultados permanecen en la memoria de esta pestaña y se pierden al cerrarla o limpiar los resultados.
    • La dirección que analizas se envía a una función serverless de Netlify, que realiza las solicitudes al sitio. La herramienta no guarda ni registra esa dirección.
    • Para buscar vulnerabilidades se envía a la API pública de NVD (NIST) únicamente el nombre y la versión del componente, nunca tu dirección.
    • El análisis de infraestructura usa consultas DNS públicas hechas desde el servidor de análisis. La información de red (ASN y país de registro de las IP) se consulta en el servicio DNS público de Team Cymru, al que solo se envía la dirección IP. No se envía tu dirección web completa.
    • El análisis de dominio usa servicios públicos: el dominio se envía a rdap.org (que redirige al registro oficial) y a Google Public DNS (DNSSEC); las IP públicas del sitio se envían a ipwho.is para estimar su ubicación. No se envían rutas ni datos tuyos, y no se muestran datos personales del titular del dominio.
    • Para listar subdominios se consultan los registros públicos de certificados (Cert Spotter y crt.sh), que reciben el dominio. Los subdominios encontrados solo se consultan por DNS; no se conecta a ellos.
    • El PDF y el JSON se generan en tu dispositivo y no se envían a ningún tercero.
